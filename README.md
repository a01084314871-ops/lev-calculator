# 국소배기 설계 계산기

산업환기 국소배기장치(LEV) 설계 단계를 따라 후드 필요환기량과 덕트 크기를 계산하는 웹 계산기입니다.

## 기능

### ① 후드 · 필요환기량
Dalla Valle 식으로 후드 형식별 필요환기량 Q를 계산합니다.

| 후드 | 식 |
|---|---|
| 부스식(포위식) | Q = Vc · W · H |
| 외부식 일반 | Q = Vc (10X² + A) |
| 외부식 플랜지 일반 | Q = 0.75 Vc (10X² + A) |
| 외부식 슬롯 | Q = 3.7 L · Vc · X |
| 외부식 플랜지 슬롯 | Q = 2.6 L · Vc · X |
| 캐노피 | Q = 1.4 P · Vc · D |

### ② 덕트 크기
- 덕트 크기 결정: A = Q / Vd, D = 2√(A/π) → 상용 규격 선정 → 실제 덕트속도
- 덕트 환기량: Q = V · A (속도압 입력 시 V = 4.043√VP)

## 사용법
`index.html`을 웹브라우저로 열면 됩니다. 설치가 필요 없고 인터넷 연결 없이도 계산됩니다.

## 참고
- 제어속도 빠른 선택값: 산업안전보건기준에 관한 규칙 별표 13
- 제어속도 범위, 최소 반송속도: ACGIH Industrial Ventilation Table 3-1, 3-2
- 계산 결과는 학습·검토용이며, 실제 설계값은 해당 물질과 작업 조건을 확인해 정해야 합니다.
